# MediCare Hospital System

A Java-based hospital management system developed as part of the Programming assignment for IIE Rosebank College.

## Features
- Patient Registration and Management
- Doctor Management
- Appointment Scheduling
- Medical Records Tracking
- Billing System

## Technologies Used
- Java (JDK 17)
- Maven
- NetBeans IDE
- Git & GitHub for version control

## How to Run
1. Clone the repository:
git clone https://github.com/Anelisiwe876/MediCareHospitalSystem.git
2. Open in NetBeans IDE
3. Build the project and run Main class
